Course Overview

This course explores the rapidly evolving field of Agentic Artificial Intelligence: AI systems capable of reasoning, planning, retrieving information, using tools, and autonomously completing tasks. Throughout the semester, you will learn how modern AI agents are designed and implemented using large language models (LLMs), orchestration frameworks, retrieval systems, memory architectures, and external APIs.

The course emphasizes practical engineering and hands-on development. Tuesdays cover concepts and architecture: agent architectures, LLM fundamentals, orchestration patterns, system design, ethics, and industry case studies. Thursdays are guided implementation labs: hands-on coding, debugging workshops, and collaborative engineering.

Working Definition An Agentic AI System is software that, given a goal expressed in natural language, chooses its own next action from a set of tools, executes that action against an external environment, observes the result, and repeats the cycle until it judges the goal to be met or gives up.
📖 Required Textbook The Agentic AI Bible — Thomas R. Caldwell — Building Autonomous AI Systems with Large Language Models, Tools, Memory, and Context. Revised & Expanded Edition, 2026.
