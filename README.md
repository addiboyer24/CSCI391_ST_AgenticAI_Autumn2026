# CSCI 391 · Agentic Artificial Intelligence — course materials

Materials for the current offering of CSCI 391 (University of Montana pilot, Autumn 2026): lab and project briefs, starter code, and the syllabus.

The course site (lessons, readings, quizzes) is on the Aideation platform: https://therealaideation.github.io/aideation-platform/csci391.html

## What's here

| Path | What it is |
|---|---|
| `Assignments/Labs/` | Lab 1–5 briefs and starter files (`requirements.txt` covers every lab) |
| `Assignments/Midterm/` | Encore — the midterm project brief and starter |
| `Assignments/Final_Project/` | Encore Ensemble — the final project brief |
| `09_10_2026/` | Code from class |
| `CSCI391_ST_Agentic_AI_Syllabus_Autumn2026.docx` | The syllabus |

## Getting started

```
git clone https://github.com/addiboyer24/CSCI391_ST_AgenticAI_Autumn2026
cd CSCI391_ST_AgenticAI_Autumn2026
python -m pip install -r Assignments/Labs/requirements.txt
```

Never commit a `.env` file: keep API keys out of the repository.
